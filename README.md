# CCL AI Suite

## Full AI tool suite


#### How To Start:
- Make sure python 3.x is installed
- Clone this repo
 ```bash
git clone https://github.com/EF-Code/ccl-suite.git
```
- Create a virtual environment
```bash
cd ccl-suite
python -m venv .venv
```
- Install dependencies
```bash
pip install -r requirements.txt
```
