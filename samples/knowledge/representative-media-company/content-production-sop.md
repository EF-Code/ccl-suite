# Content Production SOP

## Scope

This procedure applies to fictional Project Aurora videos prepared for the
small company's YouTube channels and TikTok accounts.

## Editorial workflow

1. A script writer submits a draft with a source list and proposed title.
2. A video editor works from a copy of the approved raw footage; the original
   media file remains unchanged in the project archive.
3. The editor exports a review copy to the project review folder.
4. The team lead approves the review copy before any scheduled publication.
5. The community manager receives the approved caption, moderation notes, and
   publishing window after approval is recorded.

## Asset controls

- Verify the SHA-256 checksum before restoring a media asset from backup.
- Restore an asset only to a new empty destination; never replace the original project asset.
- Report a checksum mismatch to the team lead and do not publish the affected content.
- Store editable project files in the approved project folder, not in personal
  cloud storage.

## Publishing controls

- A video may be published only after editorial approval and platform review.
- Use an approved thumbnail and caption for each platform-specific export.
- Record a failed upload without saving platform credentials in the project
  record.
