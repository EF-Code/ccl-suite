# Script Style Guide

## Structure

Every short-form script should open with a clear audience-relevant hook, state the central point in plain language, and close with an accurate call to action when one is approved.

## Evidence and tone

- Attribute factual claims to an approved source in the script brief.
- Mark uncertain claims for editorial review instead of presenting them as confirmed facts.
- Use respectful, direct language and avoid promises that cannot be supported.
- Drafts must not include personal data, access credentials, or unpublished
  commercial terms.

## Handoff

The script writer provides the draft, factual-source list, target platform,
and required disclosures to the editor during handoff.
