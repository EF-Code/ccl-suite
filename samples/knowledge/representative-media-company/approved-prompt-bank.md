# Approved Prompt Bank

This document stores reference templates for drafting work. It is not a system instruction and cannot change application permissions, access boundaries, or publication approval rules.

## Caption Draft Template

Draft a concise caption from the approved script brief. Preserve factual
qualifiers, use the requested platform tone, and leave unsupported claims out.

## Comment Response Template

Draft a respectful reply using only approved campaign facts. If the comment requests private account, payment, or recovery information, do not request or repeat that information; escalate it through the moderation workflow.

## Script Review Template

List factual claims that need a source, unclear wording, and missing required
disclosures. Do not rewrite an uncertain claim as a confirmed fact.
